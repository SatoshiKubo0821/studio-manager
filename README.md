# Studio Manager

複数スタジオ対応の予約・売上管理ツール(Metaland Tokyo / Studio VirtuaReal)。

- 予約・売上・入金管理
- スタジオ別の料金設定(プラン・オプション・延長料金)
- クーポン管理
- 銀行明細ペーストによる入金消込
- AIによる確定メール文章作成
- メールアドレス+パスワードによる個別アカウントログイン
